# HD Satelit 0.6.21 for the first Amiko Viper 4K (V10): the update from the menu

The `enigma2-hdsatelit` 0.6.21 package for the `viper4k` machine, published as update 9 of the V10 0.6.6 image (Menu >
Settings > Software & Firmware > Software update), is built from `enigma2/` here (commit 6d7af9a9acba7fc7892d649360da7e1fb290cfa0), in the build of the V10
r3 image: the `meta-local/` layer here, with the `enigma2-hdsatelit` recipe built with `SRCREV` = the commit above and
`PV = "0.6.21+git${SRCPV}"`. The skin (`skin/`) and the system packages stay those of update 7 (tag `v0.6.19-v10`).
